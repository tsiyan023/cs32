# Battleship Game in C++

**Prepared by:** Siyan Tang  
**Year:** 2024

## Description

A C++ Battleship game implementation demonstrating object-oriented design, board-state management, ship placement, player strategy logic, and turn-based game simulation.

## Features

- Board creation and validation
- Ship placement and removal
- Human, mediocre, awful, and good player strategies
- Attack result tracking
- Game loop and winner detection

## Skills Demonstrated

- C++ programming
- Object-oriented design
- Recursive/backtracking-style placement logic
- Game-state management
- Algorithmic problem solving

## Build

```bash
g++ -std=c++17 -Wall -Wextra -pedantic Board.cpp Game.cpp Player.cpp main.cpp -o battleship
./battleship
```
