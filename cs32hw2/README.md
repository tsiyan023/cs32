# Maze and Expression Algorithms in C++

Portfolio version maintained by Siyan Tang.

## Description

This repository contains C++ implementations of stack-based depth-first search, queue-based breadth-first search, and boolean expression evaluation using infix-to-postfix conversion.

## Included Files

- `mazestack.cpp`: Maze path search using a stack-based depth-first traversal.
- `mazequeue.cpp`: Maze path search using a queue-based breadth-first traversal.
- `eval.cpp`: Boolean expression parser and evaluator using postfix conversion.
